# 2026-02-25 — Late Night Session (v155→v157)

## Bugs Found & Fixed
1. **Weapon hold offset not compensating for bone world scale (32x)** — holdOffset was in world-space but applied in bone-local space. Position (0, -0.05, -0.15) became 4.8 world units away. Fix: divide holdOffset by bone world scale (`_bsi = 1 / _bws.x`)
2. **FPS viewmodel crash: `createWeaponMesh(...).then is not a function`** — `createWeaponMesh` returns a Group synchronously (GLB loads async into it), NOT a Promise. Fixed to use synchronous pattern
3. **Weapon scale too small** — Was 0.5 world units for guns, 0.9 for melee. Increased to 0.9/1.1
4. **NPC weapon scale was 5.0 (arbitrary)** — Normalized to same 0.9/1.1 as player
5. **Duplicate play mode handler** — Line ~8951 called basic `enterPlayMode()` without loading character. Added character auto-load fallback
