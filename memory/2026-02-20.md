## Key Technical Learnings
- wgpu pipelines MUST match shader bind group declarations exactly — if shader declares @group(2), pipeline layout must include it
- Can't use same shader for pipelines with different bind group layouts — split into basic.wgsl (2 groups) and basic_shadow.wgsl (3 groups)
- Cargo incremental builds can be stale — `cargo clean` when binary doesn't match source
- macOS .app bundle binary must be explicitly copied after each build
- /tmp/koko_panic.log can be stale — must `rm` before testing new builds
