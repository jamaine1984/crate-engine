## Lessons Learned
- NEVER use regex to remove "duplicate initializers" by field name — fields like `name`, `timer`, `pos` appear in constructors everywhere. Only target specific known duplicates.
- Always `git checkout` to revert bad automated edits immediately.
- Check existing structs BEFORE adding new ones to avoid field mismatches.
