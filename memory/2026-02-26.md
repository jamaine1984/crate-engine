## Key Discoveries
- **KayKit knight model forward is +Z** — rotation.y=0 shows face, rotation.y=PI shows back
- **modelContainer exists (v120 pattern)** — Wraps model in THREE.Group. Container gets position + rotation. Model rotation is ADDITIONAL on top of container.
- **Line 2104**: `this.modelContainer.rotation.y = this.rotation` — container rotates
- **Line ~2517**: `model.rotation.y` lerps to targetRot — model ALSO rotates
- **Both rotating = double rotation = 2*PI = no rotation visually**
- **Movement direction**: `moveDir = (sin(rot), cos(rot))` where sin(PI)=0, cos(PI)=-1 = -Z direction
- **Camera at +Z from character**: `(sin(yaw)*dist, h, cos(yaw)*dist)` with yaw=0 = (0, h, +dist)
