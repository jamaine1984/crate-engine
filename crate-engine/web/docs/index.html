🚀 Getting Started

Crate Engine runs entirely in your browser. No downloads, no installs, no accounts required.

Quick Start

  1. Visit crateshipgames.com
  2. Type a command in the prompt bar: build a medieval village
  3. Type play to enter the world in 3rd person
  4. Use WASD to move, mouse to look, Space to jump

⚔️ Combat System

Spawn enemies and engage in Souls-like combat:

spawn 5 enemies    — Places enemies across the map
equip sword         — Equip a melee weapon
equip axe/spear/hammer/shield

Combat Mechanics

  • Light Attack (E): 3-hit combo, each hit increases damage
  • Heavy Attack (Q): 2.5x damage, AOE knockback, screen shake
  • Dodge Roll (C): Invincibility frames, cancels attacks
  • Hitstop: Brief freeze on hit for impact feel
  • Enemies aggro when you approach, have health bars, drop loot

🚗 Vehicles

add truck  — Large truck (~6m)

add tank   — Armored vehicle (~6m)
