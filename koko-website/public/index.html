Capabilities

Everything. Built in.

Every feature a real game needs — rendering, physics, audio, AI, multiplayer — all included, all prompt-accessible.

🎮

Prompt-to-Game

Describe your game and watch it build in real-time. Add features, refine mechanics, iterate — all through natural language.

📦

Built-In Asset Library

Characters, weapons, armor, animations, environments, sounds, VFX, materials — 3,000+ assets ship with the engine. No store needed.

📁

Import Your Own Assets

Bring your own models, textures, sounds, and scripts. Support for glTF, FBX, OBJ, PNG, WAV, OGG, Lua, and dozens more formats.

🧠

Model-Agnostic AI

Works with Claude, Gemini, GPT, or local models via Ollama. Routes each task to the best AI. Never locked to one provider.

👁️

Live Preview

Every prompt change appears instantly in the viewport. Play your game at any moment. No compile, no wait.

🎨

AAA Rendering

PBR materials, global illumination, volumetric fog, post-processing, dynamic shadows — Metal 4, Vulkan, DirectX 12, WebGPU.

⚔️

Combat Systems

1,000+ built-in animations: rolls, parries, combos, backstabs, ranged, magic. Prompt "add souls-like combat" and it works.

🌍

World Generation

Procedural terrain, dungeons, cities, forests, caves. Or hand-craft with built-in environment kits. Open world streaming included.

🎵

Spatial Audio

3D audio with HRTF, reverb zones, adaptive music, 2,000+ built-in sounds. Footsteps that change on different surfaces, automatically.

🌐

Multiplayer

Client-server, P2P, lobbies, matchmaking, lag compensation — prompt "add 4-player co-op" and the networking just works.

🔌

API & Plugins

REST APIs, WebSockets, OAuth2. Plug in payment systems, analytics, cloud saves, AI services, music generation — anything.

📱

Ship Everywhere

Build for macOS, Windows, Linux, iOS, Android, and Web from a single project. Console support coming.
