# Crate Engine — Command Schema v1

> Every engine action is a versioned JSON command.
> This document is the canonical reference for all command types.

---

## 1. Command Envelope

Every command follows this structure:

```json
{
  "v": 1,
  "id": "cmd_01HQ...",
  "ts": 1709312400000,
  "source": "chat",
  "type": "SPAWN_OBJECT",
  "payload": { ... }
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `v` | number | yes | Schema version (currently `1`) |
| `id` | string | auto | Unique command ID, generated by command bus |
| `ts` | number | auto | Unix timestamp ms, generated by command bus |
| `source` | string | yes | Origin: `chat`, `voice`, `editor`, `multiplayer`, `script`, `system` |
| `type` | string | yes | Command type (see Section 3) |
| `payload` | object | yes | Type-specific data |

---

## 2. Command Result

Every command execution returns:

```json
{
  "ok": true,
  "commandId": "cmd_01HQ...",
  "message": "Added dragon at (10, 0, 5)",
  "data": { ... }
}
```

| Field | Type | Description |
|-------|------|-------------|
| `ok` | boolean | Whether the command succeeded |
| `commandId` | string | Echo of the command ID |
| `message` | string | Human-readable result for chat display |
| `data` | any? | Optional result data |

### 3.2 Object Commands

#### SPAWN_OBJECT
```json
{
  "type": "SPAWN_OBJECT",
  "payload": {
    "query": "dragon",
    "position": { "x": 10, "y": 0, "z": 5 },
    "rotation": { "y": 90 },
    "scale": 1.0
  }
}
```
- `query` (string, required): Asset search query
- `position` (object, optional): World position. Defaults to `{x:0, y:0, z:0}`
- `rotation` (object, optional): Euler degrees
- `scale` (number, optional): Uniform scale. Defaults to `1.0`

#### SCATTER_OBJECTS
```json
{
  "type": "SCATTER_OBJECTS",
  "payload": {
    "query": "tree",
    "count": 20,
    "radius": 50
  }
}
```

#### REMOVE_OBJECT
```json
{
  "type": "REMOVE_OBJECT",
  "payload": { "target": "dragon" }
}
```

#### TRANSFORM_OBJECT
```json
{
  "type": "TRANSFORM_OBJECT",
  "payload": {
    "target": "castle",
    "position": { "x": 10, "y": 0, "z": 5 },
    "rotation": { "y": 90 },
    "scale": 2.0
  }
}
```
- At least one of `position`, `rotation`, `scale` required

#### COLOR_OBJECT
```json
{
  "type": "COLOR_OBJECT",
  "payload": {
    "target": "car",
    "color": "red"
  }
}
```

#### UNDO
```json
{ "type": "UNDO", "payload": {} }
```

## 6. Versioning Rules

- Schema version (`v`) starts at `1`
- Adding new command types does NOT bump version
- Changing existing payload shapes DOES bump version
- Command bus must handle `v: 1` commands indefinitely (backwards compat)
- Deprecated commands get a `deprecated: true` flag, never removed
