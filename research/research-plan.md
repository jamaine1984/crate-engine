# Deep Research Plan — How Real Game Engines Work

## Sources to Study
1. **Three.js FPS/TPS games** — actual source code on GitHub
2. **Unity/Unreal patterns** — architecture docs, tutorials 
3. **PlayCanvas** — open source WebGL game engine
4. **Babylon.js** — Microsoft's game engine (well documented)
5. **GDevelop/Godot** — open source game engines
6. **AAA game postmortems** — how real games handle systems

## Key Systems to Research
1. Character Controller (movement, gravity, collision)
2. Weapon System (equip, fire, reload, animations, attachment)
3. Camera System (TPS, FPS, transition, collision, spring arm)
4. AI/NPC System (pathfinding, state machines, behavior trees)
5. UI/HUD System (health bars, ammo, minimap, menus)
6. Animation System (blend trees, state machines, IK)
7. Inventory System (grid, equipment slots, drag/drop)
8. Scene Management (loading, streaming, LOD)
9. Input System (key mapping, controller support)
10. Audio System (spatial, music, SFX)
